## GraphQL 重要踩坑（Zion Headless）
- **嵌套插入必须用 `students: { data: [...] }` 语法**（insert_schedule_one 内），Zion 会自动回填父 ID；平级两个 mutation 的 insert_schedule_student 不会自动带 schedule_id（会插成 null）
- **`update_xxx_many(updates:)` 不存在**（Unknown type），批量更新用动态别名逐条：`u0: update_xxx_by_pk(pk_columns:{id:$sid0}, _set:$set0)`，变量声明也要动态生成
- 先删后插（upsert 模式）在同 mutation 内原子生效：delete_where + insert_one
- 排课删除需手动级联：delete schedule_student + lesson_record + schedule（无自动级联）
- bash heredoc 里写 node 脚本会被 zsh 干扰（${} 替换），用 Write 工具写文件再执行
- toISOString() 是 UTC，日期计算注意时区（demo 数据日期偏了1天，无实际影响）

### 调研结论
- 部件识字法（谢锡金/黄沛荣，港教大验证）：高构字率独体字 → 简单合体字 → 复杂合体字
- 四五快读规律：16字即组词、32字即组句；虚词（的/有/我/是）尽早引入；101独体字可拓展400+字
- 认知规律：象形字优先、先认读后书写、每课1-2新字、15分钟内、游戏化优先于识字量

## Zion database MCP 操作参数速查（多次试错得出，复用价值高）
- ADD_TABLES：args.items[]，每项 {tableDisplayName, tableApiName, fields:[{displayName, apiName, basicTypeNameOrTypeId, required}], relations:[]}；systemName 创建后不可改，displayName 可改
- ADD_FIELDS_AND_RELATIONS：args 平铺 {tableDisplayName, fields:[], relations:[...]}（不用 items！）；关系对象：{relationType(小写 one_to_many/one_to_one), sourceTableDisplayName, targetTableDisplayName, fieldDisplayNameInSourceTable, fieldApiNameInSourceTable, fieldDisplayNameInTargetTable, fieldApiNameInTargetTable}；fieldApiNameInTargetTable 决定目标表 FK 列名（自动加 _id）；一次可跨多张源表批量加关系
- ADD_CONSTRAINTS：args.constraints[]，每项 {tableDisplayName, constraintName(小写snake_case), constraintType(大写 UNIQUE), fieldDisplayNames:[]}；FK 字段 displayName = 目标侧显示名 + "_id"
- 旧类型系统（pre_type_system_refactor）字段不能带 defaultValue；类型用小写（string/bigint/date/timetz 等）
- 流程：schema_session LOAD → database 建表/关系/约束 → VALIDATE → sync_backend 部署生效；参数错误先行校验、不会部分应用

## Zion actionflow/bindings MCP 操作速查（重要踩坑）
- ADD_ACTION_FLOWS: args.items[{displayName, description}]；建后 GET_ACTION_FLOW_DETAIL 拿 startNodeId/endNodeId
- ADD_ACTION_FLOW_NODE: args {actionFlowId, afterNodeId, node:{type, displayName, templateCodeId?, code?}}；节点类型用 CUSTOM_CODE（不是 RUN_CODE）；**code 必须在 ADD 时随 node 对象传入**（UPDATE_ACTION_FLOW_NODE 的 code 参数无效、空 diff！）；改 displayName 可用 UPDATE
- 模板节点「获取ID」templateCodeId=XmXk1me8OmD，输出 current_account_id (BIGINT)
- ADD_CUSTOM_CODE_NODE_INPUT: {actionFlowId, nodeId, name}（旧类型系统无 type）；输出值 ADD_CUSTOM_CODE_NODE_OUTPUT_VALUE: {actionFlowId, nodeId, name, type: TEXT/BIGINT...} 一个个加，不支持批量
- 流程输出：ADD_ACTION_FLOW_OUTPUT_FIELDS {actionFlowId, items[{name, type}]}；然后在 FLOW_END 节点（allNodes 最后一个）outputDataBindings.<字段> 用 bindings CREATE_OPTION_BINDING 绑到代码节点输出，路径 ["Context", "<节点displayName>", "<输出名>"]
- bindings 的 schemaPath 格式：[{key:"server"},{key:"actionFlows"},{index:0},{key:"allNodes"},{index:2},{key:"inputArgsDataBinding"},{key:"<arg>"}]；代码节点 code 不是绑定站点
- 删除节点后 FLOW_END 的旧绑定会报 Missing data 错误，需重绑
- runtime_run_code：jsCode + updateDb:true 持久化；GraphQL 表名=systemName，runGql(opName, doc, vars, {role:'admin'})，mutation 用 insert_<table>(objects:...)

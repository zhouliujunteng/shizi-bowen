## 部署问题诊断：Zeabur 静态站 404
- 用户把前端部署到自己服务器（Zeabur，域名 bowen.chuanglut.com，Caddy），选「本地直接文件夹上传」后全站 404
- 根因：上传的是整个前端**源码目录**（套了一层 `frontend/`，且未含 dist），服务器根目录无 index.html；源码 package.json/src 被直接暴露
- 本地 `frontend/dist/` 已于当天 09:41 构建好（index.html + assets/ + hanzi-data/ 187 项）
- 修复指引：重新上传时选 `frontend/dist` 文件夹本身作为根目录
- 遗留隐患：Vue Router 若为 history 模式，子路由刷新会 404 → 方案：改 createWebHashHistory 或改用 Zeabur 构建部署（zbpack 识别 Vite 自动 build + SPA fallback）

## dist 打 zip 上传的坑（重要）
- 用户偏好「zip 包直接上传」部署到 Zeabur
- ⚠️ macOS 命令行 `zip`/`ditto` 打包含中文文件名（hanzi-data/写.json 等 185 个）**不写 UTF-8 标志位**，服务器解压后文件名变乱码 → 前端请求 404。`ditto` 还会带 __MACOSX 垃圾
- ✅ 正确做法：用 Python zipfile 打包（自动写 UTF-8 flag）：os.walk dist 目录，zipfile.ZipFile(out,'w',ZIP_DEFLATED)，arcname 用 relpath，排除 . 开头文件
- 产物：项目根目录 bowen-dist.zip（616K，227 文件，index.html 在根，中文名完整）
